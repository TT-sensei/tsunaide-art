# つないでアート

点と点を線でつないで、形・模様・絵をつくる図工アプリです。静的HTML/CSS/JavaScriptで動作し、外部APIやサーバーは使用しません。

## 主な機能

- お手本／アレンジ／じゆうにつくる
- 10×10の点ボード（点を2つ順にタップして線を作成）
- 描く／消す、Undo／Redo、全消去
- 8色、線幅3段階、背景色
- お手本10作品
- localStorageへの作品保存（最大20件）
- 保存作品の一覧・再編集・削除
- 点を隠した鑑賞表示
- 作品部分だけのPNG出力

## 使い方

`index.html`をブラウザーで開いてください。ローカルファイルでも動作します。

## GitHub Pagesで公開

1. このフォルダーの中身をGitHubリポジトリのルートへアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch**、`main`、`/(root)` を選んで保存します。

## お手本の追加

`app.js`内の`samples`配列へ作品データを追加します。点番号は上段左から0〜9、次の段が10〜19です。

```js
{
  id: 'example',
  name: 'れい',
  level: 'かんたん',
  lines: [
    { from: 0, to: 11, color: '#222222', width: 6 }
  ]
}
```

## 保存について

作品は利用中の端末・ブラウザーのlocalStorageにだけ保存されます。別端末には同期されません。ブラウザーデータを削除すると作品も消えるため、提出・保管にはPNG出力を利用してください。
